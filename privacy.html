개인정보처리방침

SOS Bridge는 해외여행 중 갑작스러운 아픔이나 부상 상황에서 도움 요청을 돕는 참고 안내 서비스입니다. SOS Bridge는 의료기관, 응급기관 또는 공공기관이 아닙니다.

SOS Bridge는 의료진의 진단이나 치료를 대체하지 않습니다. 응급 상황에서는 즉시 현지 응급번호로 연락하거나 가까운 의료기관, 현지 공공기관, 숙소, 대사관 또는 영사관의 도움을 받으세요.
SOS Bridge는 의료기기가 아니며, 질병이나 건강 상태를 진단, 치료, 완화 또는 예방하기 위한 서비스가 아닙니다.

1. 서비스 소개

SOS Bridge는 한국어로 상황을 정리하고, 선택한 여행 국가/지역의 언어로 도움 요청 문장과 여행자 의료카드를 보여주는 보조 도구입니다. 사용자가 현지 의료진, 주변 사람, 숙소 직원, 공공기관에 상황을 설명할 수 있도록 돕는 것이 목적입니다.

2. 처리하는 정보

현재 앱 구조 기준으로 사용자가 직접 입력하거나 브라우저 기능을 통해 처리될 수 있는 정보는 다음과 같습니다.

  • 여행 국가/지역 선택 정보
  • 여행 도시/지역 입력 정보
  • 증상 입력 내용
  • 의료카드 입력 정보: 이름 또는 별칭, 여권상 영문 이름, 국적, 나이, 혈액형, 알레르기, 복용 중인 약, 기존 질환, 비상 연락처, 여행자 보험, 숙소 주소
  • 구조화된 개인 비상연락처 1명: 이름, 관계, 전화번호, 사용자가 최종 확인한 시각
  • 사용자가 위치 권한을 허용하는 경우의 현재 위치 정보
  • 브라우저 또는 기기에서 자동으로 처리될 수 있는 기본 기술 정보

3. 정보를 사용하는 목적

  • 여행 국가/지역 설정과 현지어 도움 문장 표시
  • 여행자 의료카드 작성, 표시, 현지어 번역
  • 응급번호 정보와 정식 지원/제한 지원 상태 표시
  • 증상 입력을 바탕으로 한 AI Care 참고 안내 제공
  • 병원·약국 검색 기준 제공 및 지도 또는 길찾기 연결
  • 서비스 안정성 확인

4. 저장 여부

현재 베타 버전에서는 별도 회원가입 계정 서버나 데이터베이스에 의료카드 정보와 증상 정보를 저장하지 않습니다.

현재 베타 버전에서는 여행자 의료카드 정보와 의료카드 번역 캐시가 사용자의 브라우저 localStorage에 저장될 수 있습니다. 이 정보는 SOS Bridge의 별도 회원 계정 서버에 저장되지 않으며, 사용자는 앱 안의 “의료카드 정보 삭제하기” 버튼 또는 브라우저 사이트 데이터 삭제 기능으로 삭제할 수 있습니다.

사용자가 직접 등록한 구조화된 개인 비상연락처 1명은 의료카드의 기존 비상 연락처 항목과 분리하여 이 기기 브라우저의 localStorage에 저장됩니다. 이 연락처는 SOS Bridge 서버, Netlify Function 또는 번역 API로 전송되지 않으며, 앱은 기기 연락처 권한을 요청하거나 기기 연락처 앱의 정보를 읽지 않습니다.

현재 앱은 응급번호 출처 페이지에서 긴급 도움 화면으로 안전하게 돌아오기 위한 비민감 복귀 표시를 sessionStorage에 최대 10분간 저장할 수 있습니다. 개인 비상연락처, 위치 또는 의료정보는 이 표시에 포함되지 않습니다. 현재 앱 자체에서 쿠키를 저장하는 별도 로직은 확인되지 않았습니다.

5. 개인정보의 처리 및 보유 기간

  • 브라우저 localStorage에 저장되는 의료카드 정보와 번역 캐시는 사용자가 삭제 버튼을 누르거나 브라우저 사이트 데이터를 삭제할 때까지 남아 있을 수 있습니다.
  • 구조화된 개인 비상연락처는 사용자가 비상연락처 관리 화면에서 삭제하거나 브라우저 사이트 데이터를 삭제할 때까지 남아 있을 수 있습니다. 브라우저 저장소 초기화, 앱 삭제 또는 기기 설정에 따라 사라질 수 있습니다.
  • 별도 회원 계정 서버 또는 데이터베이스에 저장하지 않는 정보는 서버 보유 기간이 적용되지 않습니다.
  • 외부 API를 통해 처리되는 정보는 해당 외부 서비스의 처리 정책과 기술적 처리 과정에 따라 일시적으로 처리될 수 있습니다.
  • SOS Bridge가 향후 계정 기능, 서버 저장 기능, 유료 기능을 추가하는 경우 개인정보처리방침을 업데이트합니다.

6. 개인정보의 파기 절차 및 방법

  • 사용자는 앱 안의 “의료카드 정보 삭제하기” 버튼으로 브라우저에 저장된 의료카드 정보를 삭제할 수 있습니다.
  • 사용자는 긴급 도움 화면의 비상연락처 관리에서 “연락처 삭제”를 선택해 구조화된 개인 비상연락처를 별도로 삭제할 수 있습니다. 이 삭제는 의료카드의 기존 비상 연락처 항목을 삭제하지 않습니다.
  • 브라우저 설정에서 사이트 데이터 또는 localStorage 데이터를 삭제할 수 있습니다.
  • 현재 베타 버전에서 별도 서버 데이터베이스에 저장하지 않는 정보에는 별도의 서버 파기 절차가 적용되지 않습니다.
  • 향후 서버 저장 기능이 추가되는 경우 별도 파기 절차를 고지합니다.

7. 외부 서비스 및 API 사용

현재 코드에서 확인되는 외부 처리 또는 연결은 다음과 같습니다.

  • Netlify Functions: AI Care와 번역 요청을 중계하기 위해 사용됩니다.
  • OpenAI API: 사용자가 입력한 증상 또는 번역 대상 문장을 처리하기 위해 사용될 수 있습니다.
  • Overpass API 및 Nominatim: 병원·약국 검색 또는 위치 기반 검색에 사용될 수 있습니다.
  • Google Maps 링크: 길찾기 화면 연결에 사용될 수 있습니다.
  • 브라우저 위치 권한: 사용자가 허용한 경우에만 현재 위치를 검색 기준으로 사용합니다.

8. 개인정보 처리업무의 외부 처리 가능성

SOS Bridge는 현재 별도 회원 계정 데이터베이스를 운영하지 않지만, 번역, AI Care, 병원·약국 검색, 지도 연결 등 일부 기능을 제공하기 위해 Netlify Functions, OpenAI API, 지도/검색 관련 외부 서비스가 사용될 수 있습니다. 이 과정에서 사용자가 입력한 문장, 증상 정보, 검색 위치 정보 등이 기능 제공에 필요한 범위에서 처리될 수 있습니다.

17. 긴급 도움 화면의 현재 위치 처리

  • 현재 위치는 사용자가 긴급 도움 화면의 버튼을 직접 누를 때만 요청합니다. 백그라운드에서 위치를 추적하지 않습니다.
  • 처리 항목은 위도, 경도, 정확도 및 확인 시각이며 현재 긴급 도움 화면의 메모리에서만 일시 처리합니다.
  • 위치 정보는 localStorage, sessionStorage 또는 서버에 저장하지 않으며 앱 서버나 Netlify Function으로 전송하지 않습니다.
  • 주소 변환이나 역지오코딩을 사용하지 않습니다.
  • 위치 복사, 공유 또는 외부 지도 열기는 사용자가 직접 선택할 때만 실행됩니다. 공유나 지도를 선택하면 좌표와 관련 문장이 해당 외부 앱 또는 서비스로 전달될 수 있습니다.
  • 긴급 도움 화면을 실제로 종료하거나 확정 여행 국가를 변경하면 메모리에 있던 위치 정보를 폐기합니다.
  • 현재 위치는 비상연락처 문자 내용에 기본적으로 포함되지 않습니다. 위치가 이미 확인되어 있어도 자동으로 포함하지 않으며, 사용자가 문자 확인 화면에서 “현재 위치를 문자 내용에 포함”을 직접 선택한 경우에만 복사 문구에 추가합니다. 문자 화면을 새로 열 때마다 이 선택은 다시 꺼집니다.
  • 위치 포함 선택 자체는 GPS 확인이나 위치 권한 요청을 실행하지 않습니다. 위치가 필요하면 사용자가 먼저 긴급 도움 화면의 위치 카드에서 현재 위치 확인을 직접 실행해야 합니다.
  • 위치 포함을 선택한 복사 문구에는 표시용 위도·경도, Google 지도 링크, 기기가 제공한 위치 오차 범위와 위치 확인 시각이 들어갈 수 있습니다. 의료정보는 위치 문구에 포함하지 않습니다.
  • 문자용 위치 snapshot과 위치 포함 선택 상태는 현재 앱 실행 메모리에서만 유지하며 localStorage, sessionStorage 또는 IndexedDB에 저장하지 않습니다. 해당 위치는 SOS Bridge 서버, Netlify Function 또는 번역 API로 전송하지 않습니다.
  • 사용자가 “문자 내용 복사”를 직접 눌러야 위치 문구가 시스템 Clipboard에 기록됩니다. 복사된 위치는 앱을 벗어난 뒤에도 기기에 남을 수 있고, 메시지 앱에 붙여넣으면 메시지 앱과 수신자가 위치를 처리할 수 있습니다. 공용 기기에서는 사용 후 다른 내용을 복사해 클립보드를 덮어쓰는 것을 권장합니다.
  • SMS URI에는 위치나 문자 본문을 포함하지 않으며 문자를 자동으로 전송하지 않습니다. 실제 붙여넣기와 전송은 메시지 앱에서 사용자가 결정합니다.

  • 이 기능은 사용자가 직접 입력하고 확인한 개인 연락처 1명을 이 기기 브라우저에 저장합니다.
  • 기기 연락처 앱이나 Contacts API에 접근하지 않고, 계정 서버 또는 다른 기기와 동기화하지 않습니다.
  • 전화 앱은 사용자가 전화 확인 화면의 “전화 앱 열기”를 직접 눌렀을 때만 요청되며, 자동 통화하거나 자동 발신하지 않습니다. 실제 발신은 전화 앱에서 사용자가 결정합니다.
  • 최종 확인된 phoneDial만 기기의 전화 앱 또는 운영체제로 전달될 수 있습니다. 이름, 관계, 위치와 의료정보는 함께 전달하지 않습니다.
  • 전화 앱 열기 과정에서 번호를 SOS Bridge 서버, Netlify Function 또는 번역 API로 전송하지 않습니다. 전화 앱, 운영체제와 통신사는 각자의 정책에 따라 번호를 처리할 수 있습니다.
  • 이 기능은 자동 문자 전송 기능이 아닙니다.
  • 문자 앱은 사용자가 문자 확인 화면의 “문자 작성 화면 열기”를 직접 눌렀을 때만 요청되며, 최종 검증된 phoneDial만 기기의 메시지 앱 또는 운영체제로 전달될 수 있습니다.
  • 문자 본문은 SMS URI로 자동 전달하지 않습니다. 사용자가 고정 도움 요청 문구를 복사하면 시스템 클립보드에 남을 수 있으며, 실제 전송 여부와 내용은 메시지 앱에서 사용자가 직접 결정합니다.
  • 이름, 관계, 위치와 의료정보는 메시지 앱에 자동 전달하지 않으며, 문자 앱 열기 과정에서 번호나 문구를 SOS Bridge 서버, Netlify Function 또는 번역 API로 전송하지 않습니다. 메시지 앱, 운영체제와 통신사는 각자의 정책에 따라 번호와 사용자가 작성한 내용을 처리할 수 있습니다.
  • 전화번호 복사는 사용자가 “전화번호 복사”를 직접 누를 때만 실행되며, 검증된 정규화 전화번호(phoneDial)만 시스템 클립보드에 기록합니다.
  • 이름, 관계, 위치 또는 의료정보는 전화번호와 함께 복사하지 않고, 자동 복사하거나 SOS Bridge 서버로 전송하지 않습니다.
  • 클립보드에 복사된 번호는 앱을 나간 뒤에도 기기에 남을 수 있습니다. 공용 기기에서는 사용 후 다른 내용을 복사해 덮어쓰는 것을 권장합니다.
  • 브라우저가 Clipboard 기능을 지원하지 않거나 보안 연결 요건을 충족하지 않으면 표시된 번호를 길게 눌러 직접 복사하도록 안내합니다.
  • 사용자는 저장된 번호의 정확성과 최신성을 직접 확인해야 합니다.
